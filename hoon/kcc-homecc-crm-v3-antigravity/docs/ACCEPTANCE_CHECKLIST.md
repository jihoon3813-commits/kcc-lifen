# 인수 확인 항목

## 화면 패키지
- [ ] npm run dev로 7개 메뉴가 표시된다.
- [ ] 고객 검색·필터·상세·등록·상담/상태 저장이 작동한다.
- [ ] 고객 상세/등록/견적 편집이 우측 패널로 표시되며 상하 여백이 없다.
- [ ] 390px 모바일에서 패널이 전체 화면이고 내용 스크롤이 가능하다.
- [ ] 닫기·Esc·배경 클릭이 작동한다.
- [ ] CSV 예시의 원가가 8,000,000원, 마진 20%의 VAT 포함 견적이 11,000,000원이다.
- [ ] 고객 미리보기에는 내부 원가와 마진이 없다.
- [ ] 파트너 체험 화면에서는 해당 고객/계약만 목록에 표시된다.
- [ ] 카드/렌탈 실제 처리와 체험 상태를 혼동하지 않도록 안내한다.

## 운영 연결 후
- [ ] 파트너가 다른 고객·파일·견적 ID를 요청해도 서버에서 거부한다.
- [ ] 계정 중지/권한 변경이 즉시 반영된다.
- [ ] 고객 검증·OTP 오입력 제한·토큰 만료가 적용된다.
- [ ] 실제 XLSX 병합셀·빈행·단가/합계·VAT를 검증하고 원본과 대조한다.
- [ ] 분석 실패 후 샘플 데이터가 실제 견적으로 발행되지 않는다.
- [ ] 계약은 선택된 발행본과 일치하며 새 견적으로 금액이 덮어써지지 않는다.
- [ ] 카드 성공/실패/대기/취소/부분취소/중복 웹훅을 구분한다.
- [ ] 선금·잔금·환불·렌탈 정산액이 정확하다.
- [ ] 신분확인 파일·서명·동의 버전과 접근 이력을 관리한다.
- [ ] 랜딩의 상품·파트너·UTM이 고객 접수에 연결된다.
- [ ] 실제 기간별 통계 및 IP 마스킹·중복 제외가 적용된다.
- [ ] 이전 데이터의 건수·고객별 이력·기존 링크를 대조한다.

## 패키징 검증 범위
소스는 배포 버전 2에서 그대로 복사한 파일입니다.
최신 패널은 PC 고객 상세/등록 및 390px 모바일 등록에서 가장자리와 높이를 확인했습니다.
ZIP 제작 시 JavaScript 구문, 로컬 미리보기 서버, 소스 동일성, ZIP 무결성을 확인합니다.
위 체크박스는 개발 인수용이며 운영 연결 항목을 완료된 것으로 표시하지 않았습니다.
