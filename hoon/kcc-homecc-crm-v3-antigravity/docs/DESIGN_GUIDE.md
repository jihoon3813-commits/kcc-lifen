# 디자인 가이드

## 최신 모달 스타일
공통 openDialog()와 .overlay/.dialog를 통해 모든 앱 모달을 오른쪽 전체 높이 패널로 표시합니다.
- 오른쪽 가장자리 고정, 위·아래 여백 0, 모서리 반경 0.
- 높이 100dvh / 100vh 폴백.
- 기본 폭 최대 650px, 고객 상세 .wide 최대 1260px, 견적 편집 .quote-dialog 최대 1060px.
- 데스크톱에서는 왼쪽 배경 일부가 보입니다.
- 620px 이하에서는 전체 너비를 사용합니다.
- 헤더 및 표준 폼 푸터는 고정 영역, 긴 내용은 내부 스크롤.
- 고객 상세 PC의 좌측 필드/중앙 상담/우측 이력은 각각 스크롤합니다.
- 오른쪽에서 진입하는 애니메이션. reduced-motion이면 제거합니다.
- 닫기, Esc, 배경 클릭, 키보드 포커스 이동을 유지합니다.

app/style.css 끝의 'Full-height right drawers' 블록이 최신 변경입니다.
패널 폭 조절, 이전/다음 고객 이동, 미저장 경고는 미구현 후속 제안입니다.

## 유지할 시각 요소
네이비 사이드바, 밝은 회색 작업영역, 흰색 카드, 블루 버튼, 상태별 배지.
아이콘은 inline SVG이며 글꼴은 Noto Sans KR와 시스템 폴백을 사용합니다.
고객 상세의 헤더 정보와 3열 구조를 유지하고, 작은 화면에서는 기존 반응형 배열을 사용합니다.
