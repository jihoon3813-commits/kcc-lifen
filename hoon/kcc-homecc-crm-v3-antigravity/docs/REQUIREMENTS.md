# 업무 요구사항

제품: KCC홈씨씨 CRM 3.0 / 운영사: (주)라이프앤조이

## 고객·견적·계약 흐름
1. 상품별 랜딩 상담 신청 또는 관리자 직접 등록.
2. 상담사가 고객 상세정보와 공사 희망사항 기록.
3. 가견적요청 상태에서 KCC홈씨씨 영업지원팀이 가견적 산출.
4. 원본 웹링크로 전달된 엑셀을 상담사가 다운로드.
5. 견적관리에서 엑셀 등록 → 마진 조정 → 고객용 견적 발행.
6. 고객이 조회 링크에서 이름/휴대폰을 입력하고 검증 후 모바일 견적 확인.
7. 실측 요청 → 실측 진행 → 최종 견적 → 계약.
8. 일시불(현금/카드, 선금·잔금 가능) 또는 렌탈.
9. 렌탈은 견적서에서 상담/신청으로 이어지고 서류·동의·서명, 심사·약정·정산을 관리.

## 메뉴
| 메뉴 | 요구사항 |
| --- | --- |
| 고객관리 | 등록·배정·상태·라벨·유입채널·일정·견적/내관도 링크·상담/피드백·변경이력 |
| 견적관리 | 원본 URL·엑셀·필드 매핑·마진/VAT·가견적/최종견적·버전·고객 조회/열람 |
| 계약관리 | 계약조건·첨부·선금/잔금·현금/카드·취소/환불·렌탈 접수/보완/심사/약정/정산 |
| 상품관리 | 상품 랜딩 URL·파트너 전용 링크 |
| 파트너관리 | 영업파트너 등록·전용 관리자·자사 고객/계약/상품 |
| 통계관리 | 당일/전일/주간/월간/지정기간·상품별 방문·유입경로/IP·등록/계약 이벤트 |
| 설정 | 라벨·진행구분·양식·사용자 소속/이름/연락처/이메일/아이디/권한·비밀번호 발급/재설정·초기화 |

고객의 진행구분과 견적/계약/수납/렌탈 상태는 별도로 관리합니다. 신청완료가 곧 계약완료 또는 수납완료를 뜻하지 않습니다.

## 운영 전 확정할 항목
- 실제 KCC 엑셀 양식과 원가/VAT 기준.
- 렌탈사·기간·월액·총납입액·요구서류·약정조건.
- 카드 PG 및 가맹 주체·한도·수수료·정산·취소조건.
- 실측팀/영업지원팀 사용권한, 파트너 수수료/정산.
- 운영 동의서·계약서·개인정보 보관/파기 정책.
위 항목은 이 시안에서 확정된 값이 아닙니다.
