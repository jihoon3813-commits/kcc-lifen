## 계산
원가 = 수량 × 원가단가 합계.
VAT 제외 판매가 = 원가 ÷ (1 − 매출 기준 마진율/100).
판매가와 VAT를 각각 원 단위 반올림 후 합산합니다.
예: 원가 8,000,000원, 마진 20% → 판매가 10,000,000원 + VAT 1,000,000원.
마진율은 원가 가산율과 다릅니다. 매출총이익은 PG·영업 수수료 차감 전입니다.

## 코드 위치
- initial(): 예시 초기 데이터
- render(), *Page(): 메뉴 화면
- openDialog(), openCustomer(): 패널 및 고객 상세
- openEditor(), renderEditor(), editorSummary(): 견적
- parseCSV(): CSV 4개 열 파싱
- quoteMarkup(), openPreview(): 고객 견적 미리보기
- rentalStep(): 렌탈 체험
- save(), audit(): 브라우저 저장·이력

## 데이터 한계
localStorage와 역할 선택기는 운영 보안 경계가 아닙니다.
고객 UI에서 원가/마진이 보이지 않는 것과 서버 정보보호는 별개입니다. 고객 응답에서 내부 필드를 제거해야 합니다.
통계와 날짜, 렌탈료는 예시입니다. 실제 실적으로 이관하지 않습니다.
실제 XLSX 분석, 신분증 업로드, 손서명 수집, 카드 승인 기능이 이 ZIP에 완성된 것으로 안내하면 안 됩니다.
