# 안티그래비티 작업 지시서

(주)라이프앤조이의 KCC홈씨씨 CRM 3.0 관리자 시스템입니다. 현재 화면을 기준으로 실제 운영 기능을 개발합니다.

## 먼저 확인
- README.md와 docs/IMPLEMENTATION_STATUS.md를 읽고 `npm run dev`로 실행하세요.
- 고객 목록 → 상세 → 견적 작성 → 모바일 미리보기 → 계약/렌탈 흐름을 확인하세요.
- app/의 HTML·CSS·JavaScript는 배포된 시안 원본입니다.
- 우측 전체 높이 패널은 사용자가 확정한 최신 변경입니다. 중앙 정렬 모달로 되돌리지 마세요.
- 패널 폭 드래그, 이전/다음 고객 이동, 미저장 변경사항 경고는 아직 구현되지 않은 후속 제안입니다.

## 유지할 화면
1. 네이비 사이드바·블루 강조색·라이프앤조이 표기.
2. 고객/견적/계약/상품/파트너/통계/설정 7개 메뉴.
3. 고객 목록의 상태·라벨·고객정보·유입·담당자·상담/피드백·견적 링크.
4. 고객 상세의 상태/일정, 상담/피드백/견적/계약/자료 탭, 변경 히스토리.
5. 오른쪽에 붙는 패널, 상하 여백 0, 내부 스크롤, 고정 헤더와 표준 폼 하단 버튼.
6. 고객용 화면에서 공급원가·마진·내부 메모를 숨기는 원칙.

## 개발 순서
### 1. 서버 저장과 권한
고객과 공사건을 분리하고 DB/API를 연결합니다. 본사·상담사·견적 담당자·파트너·회계 권한을 정의합니다. 파트너 범위는 서버에서 검증합니다. localStorage와 역할 선택기는 운영 인증으로 사용하지 않습니다.

### 2. 견적 처리
KCC 원본 URL·파일 보관, 실제 XLS/XLSX 파싱, 필드 매핑, 원본과 금액 검증, 마진 조정, 불변 발행본을 구현합니다. 실제 엑셀 양식이 없으면 샘플 품목으로 분석 완료를 표시하지 마세요.

### 3. 고객 조회와 계약
이름·휴대폰 입력 후 OTP 등 검증을 적용합니다. demo_quote 쿼리는 실제 인증이 아닙니다. 계약은 특정 견적 버전의 금액·범위를 고정 참조합니다.

### 4. 결제와 렌탈
현금 기록과 PG 승인내역을 구분합니다. 서버 승인 확인 전 카드 수납완료로 처리하지 않습니다. 렌탈 접수·서류·심사·약정·정산을 각각 관리합니다. 실명서류·서명은 서버 보관과 접근 정책 확정 후 연결합니다.

### 5. 마케팅·운영
상품·파트너 링크와 유입정보를 고객 접수에 연결합니다. 예시 통계는 서버 이벤트로 교체합니다. 사용자 및 양식 버전, 운영 데이터 이전·백업을 구현합니다.

## 완료 결과물
변경 내용, 실제 연결 기능, 미연결 항목, 실행/배포법, 비밀값 없는 환경변수 예시, 데이터 이전/되돌리기 방법, 인수 확인 결과를 제출하세요.

현재 운영 계정이나 비밀키는 이 ZIP에 없습니다. 기존 운영 시스템에 접근할 정보는 안전한 설정 절차로 연결합니다. 이전 모바일 견적서 전체 디자인/서명 기능을 재사용하려면 별도 패키지를 추가한 후 통합하세요.
