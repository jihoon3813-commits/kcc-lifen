# KCC 홈씨씨 모바일 견적서 + 렌탈 신청

버전 2.0.0 / 2026-11-11 / 안티그래비티 개발 인계 패키지

기존 모바일 견적서에 3단계 렌탈 신청 화면을 적용했다. 관리자 화면은 가상 신청 6건으로 동작을 확인할 수 있는 시안이며, 실제 접수 연동은 아래 개발 문서 기준으로 구현한다.

## 바로 실행하기

Node.js 18 이상에서 압축을 풀고 해당 폴더를 열어 다음 명령을 실행한다. 외부 패키지 설치가 필요 없다.

```sh
npm run dev
```

- 고객 견적서: http://localhost:4173/
- PC에서 모바일 크기로 보기: http://localhost:4173/mobile.html
- 관리자 시안: http://localhost:4173/admin.html
- 구문 검사: `npm run check`
- 종료: Ctrl+C

## 체험 순서

1. 견적서의 결제 방법에서 렌탈 카드 중 하나를 선택한다.
2. `상담하기 / 렌탈 신청하기` 중 강조된 렌탈 신청하기를 누른다.
3. 생년월일을 숫자 8자리로 입력하고 금액 확인에 체크한다.
4. **신분증 대신 개인자료 없는 테스트 이미지**를 선택한다. 실제 파일 선택·미리보기·교체·삭제 기능이 작동한다. 카메라 촬영은 모바일 기기의 표준 파일 선택 동작을 이용한다.
5. 필수 약관 전체 또는 개별 동의 후 캔버스에 직접 서명한다.
6. 신청 완료 체험 화면을 확인한다. 실제 접수나 외부 전송은 없다.
7. 관리자 시안에서 가상 신청의 상세·서류 표시 영역·동의·처리 이력을 확인한다.

## 구현된 것 / 운영 연결이 필요한 것

| 구분 | 이번 패키지 |
|---|---|
| 기존 견적과 결제 비교 | 유지 + 렌탈별 이중 CTA |
| 신청 화면 | 정보 확인 → 사진 등록 → 동의·서명 |
| 생년월일 | 자동 하이픈, 실제 날짜·미래 날짜 검사 |
| 금액 | 선택한 렌탈의 초기·월·총액 표시 및 확인 체크 |
| 첨부 | 사진 선택/촬영 입력, 1장·10 MiB 제한, 파일 헤더 기초 검사, 미리보기·교체·삭제 |
| 약관 | 필수 3종, 전체/개별 동의, 펼침, 교체 가능한 설정 |
| 서명 | 실제 포인터 입력, 확대/초기화, 관련 입력 변경 시 재서명 |
| 완료 | 명시적인 체험 완료. 운영 어댑터는 저장 성공 응답에서만 완료 표시 |
| 관리자 | 예시 데이터 목록·검색·상태 필터·상세·동의·메모·처리 이력 UI |
| 접수 서버·인증·파일 보관 | 미구현. API_CONTRACT.md에 연동 규격 제공 |
| 관리자 실제 자료 열람 | 미구현. ADMIN_PLAN.md에 인증·권한·감사·보완 흐름 제공 |

| 파일 | 역할 |
|---|---|
| ANTIGRAVITY_PROMPT.md | 안티그래비티에 전달할 작업 지시 |
| DEVELOPMENT_NOTES.md | 원본 견적 통합 지점과 운영 전환 설명 |
| docs/ADMIN_PLAN.md | 관리자 기획, 상태, 권한, 민감 서류 열람, 보완 |
| docs/API_CONTRACT.md | 고객/관리자 API·데이터·저장 및 중복 처리 |
| docs/QA.md | 실제 확인한 범위와 추가 검증 항목 |
| web/index.html, styles.css, app.js | 기존 견적서 + 상담 시안 |
| web/rental-config.js | 렌탈 금액·약관·연동 설정 교체 지점 |
| web/rental.js, rental.css | 신청 모달 동작 및 디자인 |
| web/admin.html, admin.css, admin.js | 관리자 UI 시안 |
| web/mobile.html | 390px 모바일 미리보기 |
| web/assets/ | 로고·공간 이미지 |
| scripts/serve.mjs | 로컬 정적 서버 |
| ASSET_SOURCES.md | 이미지 출처와 운영 교체 안내 |
| SHA256SUMS.txt | 파일별 SHA-256 |

약관은 초안이며 `mode: 'demo'`가 기본이다. mode만 live로 바꿔도 실제 접수 기능이 완성되지 않는다. 접수 API, 고객 인증, 비공개 파일 저장, 관리자 권한을 구현하고 승인된 약관을 적용한 후 운영으로 전환한다. 실제 계약 체결과 신용조회 자동 연계는 이 프런트 코드의 기능이 아니다.
