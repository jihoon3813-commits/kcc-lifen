## 현재 구현 범위

- 평형별 카드 → 상담 평형 자동 선택
- 교체 공간 → 추가 정보 영역 열기 및 공간 자동 선택
- 월 납입금 상담 / 무료 실측 예약에 따른 버튼 문구 변경
- 모바일 메뉴, 모바일 고정 CTA와 폼 노출 시 CTA 숨김
- 공간 연출 탭과 키보드 이동
- 전후 비교 슬라이더와 키보드 조작
- FAQ 펼침, 보증·개인정보·완료 모달
- 휴대전화 자동 하이픈, 필수 입력 검증

## 아직 연결하지 않은 기능

DB, 관리자 화면, 담당자 배정, 문자·이메일·카카오 알림, CRM, 광고 전환 측정, 실시간 견적 계산은 포함되어 있지 않습니다. 현재 요금은 카드형 안내 예시이며 계산기의 실시간 산출값이 아닙니다.

실제 접수 기능을 추가하는 경우 권장 처리 흐름은 다음과 같습니다.

1. 이름·전화·지역·동의 등 입력을 서버에서도 검증합니다.
2. 동의문 버전과 동의 시각을 상담 정보에 함께 저장합니다.
3. 서버에서 접수 ID를 생성해 DB에 저장하고 담당자 알림으로 연결합니다.
4. 저장 성공 응답을 받은 뒤 접수 완료 화면을 표시합니다.
5. 실패 시 입력 내용을 유지하며 재시도할 수 있게 하고 중복 접수를 방지합니다.

외부 서비스 키나 DB 인증 정보는 브라우저 코드에 넣지 않습니다. 기존 전화 상담 링크는 판매사 번호 `1588-0883`이며, 테스트 중 실제 전화를 걸 필요가 없습니다.

## 상품조건 확인 항목

원본 페이지 푸터는 규격·견적 조건 등을 기획용 예시로 안내합니다. 아래 항목은 이 패키지에서 임의로 확정하지 않았습니다.

| 항목 | 현재 안내와 확인할 내용 |
| --- | --- |
| 월 납입 예시 | 24평 154,000원, 32평 198,000원, 40평 245,000원, 48평 이상 290,000원. 창수·사양·기간에 따라 실제 견적이 달라짐 |
| 카드 적용 예시 | 114,000 / 158,000 / 205,000 / 250,000원. 카드 예시는 월 40,000원 차감인데 원본 주석은 전월 30만원 사용·월 최대 25,000원 할인으로 서로 다름. 실제 카드 상품 확인 필요 |
| 보증 | 최장 13년. 모든 부품에 13년이 동일하게 적용되는 것으로 확정하지 않음. 하드웨어·씰·방충망 등은 품목별 보증서 확인 |
| 성능 수치 | 차음 35dB 이상, 적외선 70%, 자외선 99%, 냉난방비 최고 40% 등의 원본 수치는 모델·시험 기준 확인이 필요한 예시로 표시 |
| 에너지 비용 지수 | 2020~2023년의 100 / 106 / 118 / 135.6은 원자료가 확인되지 않은 기획 수치임을 표시 |
| 시공 전후 | 부천 32평·26mm 유리·온도 약 4℃ 상승은 실증 시공자료가 아닌 원본 예시. 사진도 연출 이미지로 표시 |
| 4대 프로모션 | 무상 유리 업그레이드·핸들·철거/수거·방충망의 기간, 적용 지역, 사양, 대상 계약 확인 필요 |
| 방충망 | 별도 성능 확인 없이 추락 방지용 안전시설로 안내하지 않음 |
| 계약 | 초기 비용, 약정 36~60개월, 첫 출금일, 중도상환·명의승계의 실제 계약 기준 확인 필요 |

사용자가 확정 자료를 제공하면 해당 카드·FAQ·보증 모달·조건 안내를 함께 업데이트합니다. 증빙되지 않은 수치를 임의로 확정 표현으로 바꾸거나 연출 이미지를 실제 고객 사례로 바꾸지 않습니다.

## 반응형·동작 검수 인계

직전 작업에서 360·390·430px 모바일, 768px 컨테이너, 1440px PC 컨테이너를 확인했으며 가로 넘침이 없었습니다. 평형·공간 선택, 전후 슬라이더, 미리보기 제출 동작도 확인했습니다. 환경과 구현이 바뀌는 경우 해당 부분을 다시 검수하세요.
