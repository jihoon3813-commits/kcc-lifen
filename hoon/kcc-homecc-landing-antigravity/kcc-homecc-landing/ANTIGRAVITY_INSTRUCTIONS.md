# 안티그래비티 작업 지시서

## 작업 기준

이 패키지는 이미 디자인과 반응형 동작을 구현한 KCC 홈씨씨 창호 렌탈 랜딩페이지입니다. 사용자는 기존 디자인을 유지하면서 원본 상품 안내 페이지의 섹션을 모두 추가하도록 요청했고, 해당 추가 작업을 마친 버전입니다.

새 디자인으로 다시 만들기보다 현재 화면을 기준으로 요청받은 부분을 수정합니다. 기존 HTML/CSS/JavaScript만으로 실행되므로 작업상 필요한 이유가 없으면 프레임워크를 도입하지 않습니다.

## 유지할 디자인

- 배경: 아이보리 `#faf8f3`, 크림 `#f2eee5`
- 기본 글자와 강조 배경: 딥그린 `#293b35`
- 주요 버튼과 강조 문구: 오렌지 `#d96d28`
- 보조 글자 `#737a73`, 구분선 `#e3e4dc`, 세이지 `#dce3d7`
- 글꼴: `assets/pretendard.woff2`, 가변 폰트
- 본문 최대 너비: 1240px
- 밝은 실내 이미지, 충분한 여백, 큰 제목, 얇은 선 아이콘, 완만한 모서리
- PC 상단 고정 메뉴와 모바일 하단 상담 버튼
- 작은 모바일 화면의 요금 카드는 한 장씩 읽기 쉬운 배치

## 구현상 유의점

1. `style.css` 이후 `expanded.css`, `app.js` 이후 `expanded.js` 순서를 유지합니다.
2. `expanded.js`는 `app.js`의 `setSize()`를 사용합니다. 임의로 모듈 스코프를 분리하면 연결이 끊길 수 있습니다.
3. 평형 선택은 `data-size` / `data-plan-size` 값과 `#customer-size`의 옵션을 함께 맞춥니다.
4. 공간 선택은 `data-scope` 값과 `#customer-scope` 옵션을 함께 맞춥니다.
5. 주요 버튼은 `data-purpose="cost"` 또는 `data-purpose="measure"`를 통해 상담 목적을 반영합니다.
6. 모달은 네이티브 `<dialog>`를 사용합니다. 닫기·Escape·초점 복원 동작을 유지합니다.
7. 전후 비교는 `#comparison-range`의 값을 `--reveal`에 반영합니다. 터치와 키보드 조작을 유지합니다.
8. `dist/assets/`의 파일명과 상대경로를 보존합니다. 로고·연출 이미지 출처는 두 개의 `sources.json` 목록에 기록되어 있습니다.
9. 현재는 상담 정보를 외부에 전송하거나 브라우저에 저장하지 않습니다. 실제 저장 기능이 없는 상태에서 접수 성공 문구만 바꾸지 않습니다.

## 작업 후 확인

- 모바일 360·390·430px, 태블릿 768·1024px, PC 1440px에서 가로 넘침·겹침을 확인합니다.
- 모바일 메뉴를 열고 섹션으로 이동한 뒤 메뉴가 닫히는지 확인합니다.
- 평형 카드와 공간 선택이 상담 폼에 반영되는지 확인합니다.
- 공간 연출 탭, 전후 슬라이더, FAQ, 모달을 확인합니다.
- 상담 폼의 필수 입력, 전화번호 형식, 동의 체크 검증을 확인합니다.
- 실제 API 연결을 요청받았다면 성공·실패·중복 제출과 담당자 접수 결과를 함께 확인합니다.
