## 안티그래비티에서 시작하기

1. ZIP을 압축 해제합니다.
2. `kcc-homecc-landing` 폴더 전체를 안티그래비티에서 엽니다.
3. `ANTIGRAVITY_INSTRUCTIONS.md`를 읽도록 요청합니다. 파일 하단의 시작 프롬프트를 그대로 붙여 넣어도 됩니다.
4. 아래 방법으로 페이지를 실행한 뒤 수정 작업을 진행합니다.

## 실행하기

Node.js가 설치되어 있으면 프로젝트 루트에서 다음 명령을 실행합니다.

```sh
npm run dev
```

패키지를 내려받을 필요가 없어 `npm install`은 생략합니다. 터미널에 표시되는 로컬 주소를 브라우저에서 엽니다. 기본 주소는 `http://127.0.0.1:8080`입니다. 종료는 터미널에서 Ctrl+C를 누릅니다.

8080 포트를 사용 중이면 다음처럼 다른 포트를 지정합니다.

```sh
npm run dev -- --port 8081
```

Python을 사용하는 경우에는 다음 명령으로도 실행할 수 있습니다.

```sh
python -m http.server 8080 --bind 127.0.0.1 --directory dist
```

단순 화면 확인은 `dist/index.html`을 직접 열어도 가능하지만, 수정·검수는 로컬 서버 실행을 권장합니다.

## 파일 구성

| 경로 | 용도 |
| --- | --- |
| `dist/index.html` | 전체 19개 섹션의 문구, 요금 예시, FAQ, 상담 폼, 모달 |
| `dist/style.css` | 기존 랜딩의 공통 디자인과 반응형 스타일 |
| `dist/expanded.css` | 추가 상품 안내 섹션과 모바일 요금 카드 스타일 |
| `dist/app.js` | 메뉴, 평형·상담 목적 선택, 공간 탭, 모달, 입력 검증 |
| `dist/expanded.js` | 요금 카드·교체 공간 선택 연결, 전후 비교 슬라이더 |
| `dist/assets/` | 로고, 이미지, 아이콘, 로컬 폰트, 이미지 출처 목록 |
| `tools/preview.mjs` | 외부 패키지가 필요 없는 로컬 미리보기 서버 |
| `ANTIGRAVITY_INSTRUCTIONS.md` | 디자인 유지 원칙, 수정 위치, 시작 프롬프트 |
| `HANDOFF_NOTES.md` | 전체 섹션 목록, 실제 상담 연결 시 작업 범위, 확인할 상품조건 |
| `SOURCE_MANIFEST.json` | 인계 기준 소스와 앱 파일의 SHA-256 목록 |

화면 구현에 필요한 이미지·폰트는 모두 포함되어 있습니다. CSS와 JavaScript는 기존 HTML의 로딩 순서를 유지하세요. 특히 `app.js` 다음에 `expanded.js`가 실행되어야 합니다.

## 배포

정적 웹 호스팅에 올릴 대상은 **`dist/` 폴더의 내용 전체**입니다. 별도 빌드 명령은 없습니다. `tools/`와 인계 문서는 배포할 필요가 없습니다.

원래 서비스의 Git 이력, 인증 정보, 계정 연결 설정, 호스팅 식별자는 포함하지 않았습니다. 이 ZIP을 수정하거나 실행해도 현재 운영 중인 원본 상품 페이지나 완성된 랜딩에 자동 반영되지 않습니다.
